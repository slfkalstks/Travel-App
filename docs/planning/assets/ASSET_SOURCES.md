출처: [Simple Icons 저장소](https://github.com/simple-icons/simple-icons). 커뮤니티가 관리하는 아이콘 자산이며 각 기술 공급사의 공식 배포 파일이라고 주장하지 않는다. 아래 원본을 내려받아 SVG path만 구조도에 포함하고 색을 단색으로 맞췄다.

- [Kotlin 원본](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/kotlin.svg) → `brand/kotlin.svg`
- [Spring Boot 원본](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/springboot.svg) → `brand/springboot.svg`
- [PostgreSQL 원본](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/icons/postgresql.svg) → `brand/postgresql.svg`
- [라이선스 원본](https://raw.githubusercontent.com/simple-icons/simple-icons/develop/LICENSE.md) → [보관본](brand/LICENSE-SIMPLE-ICONS.txt)

Simple Icons의 CC0 배포와 별개로 브랜드명·상표 권리가 사라지는 것은 아니다. 발표자료에서 사용 기술을 식별하는 용도로 사용하며 제휴·공식 인증을 암시하지 않는다.

## 자체 작성 도형

휴대전화·파일·폴더·DB 아이콘, 연결선, 배치와 색상은 프로젝트 설명을 위해 직접 작성했다. `system-architecture.svg`와 `presentation-concept.svg`는 외부 네트워크 요청 없이 열 수 있다. PNG는 같은 SVG를 렌더링한 미리보기다.

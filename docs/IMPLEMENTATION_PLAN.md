# 모바일 구현 범위 및 검증 계획

2026-11-01 사용자 피드백에 따라 기존 UI를 전부 교체했다. 제품 대상은 Android와 iOS이다.

## 이번 구현

- 공통 Compose UI: 여행, 항공권, 장소, 기록, 설정
- 여행 상세: 일정, 준비물, 예약, 경비
- 일정: 추가, 날짜·시간·제목·분류·장소·메모 전체 수정, 메모만 수정, 일정명·날짜를 확인한 뒤 삭제
- 준비 항목: 추가·이름/분류 수정·삭제 확인·완료 체크. 수정 시 기존 완료 여부 보존
- 기타 저장: 지출·메모 추가, 장소 저장
- 일정의 예상 비용·좌표는 전체 수정 요청에서 제외하고 서버의 기존 값 보존
- 상세에서 작성 중인 메모는 저장 성공 후 전체 수정 화면으로 이동; 실패하면 입력 유지
- 외부 연결: 노선·날짜를 반영한 Google 항공편 검색, 장소별 Google 지도
- 날짜·시간·금액 검증, 필드별 오류, 실패 시 입력 유지, 재시도 중복 생성 방지
- 밝은 화면과 어두운 화면, 동작 줄이기

일정 전체 수정·삭제와 준비 항목 관리는 프런트엔드 화면·입력·확인 흐름을 먼저 구성한 다음 서버 저장 기능에 연결했다. 최신 기능의 API·공통 상태 테스트와 iOS 입력·저장 검수 결과는 [검증 기록](VERIFICATION.md)에 정리했다.

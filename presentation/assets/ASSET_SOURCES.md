# 발표자료 자산

2026-11-01 작성.

## 실제 앱 화면

`home-screen.png`, `flow-screen.png`, `destination-screen.png`는 iPhone 16 Pro / iOS 18.2 Simulator의 **File → Save Screen…**, **Apply device mask**로 내보냈다. 각각 1206×2622, 알파 채널이 있는 원본 PNG다. 모니터·창 프레임·마우스 포인터를 포함하지 않는다. 화면 안 데이터와 UI를 바꾸거나 합성하지 않았다. PPT에는 같은 크기의 얇은 검은 외곽선만 추가했다.

미저장 여행 생성 폼에서 일본을 선택해 도시 목록을 캡처한 뒤 폼을 닫고 기존 홈으로 복귀했다. 기존 여행 데이터는 변경하지 않았다.

## 시작 화면 디자인

`splash-phone.png`는 사용자가 요청한 표지용 앱 아이콘·로딩 화면을 image_gen으로 새로 생성한 디자인 콘셉트다. 투명 배경, 차콜 화면, 라임 경로 심볼과 앱 이름 ‘여정’을 사용했다. 실제 앱 실행 캡처나 시작 기능 구현 증거가 아니다.

## 기술 도형

Kotlin·Spring Boot 브랜드 아이콘의 출처와 CC0 라이선스는 [기존 자산 출처](../../docs/planning/assets/ASSET_SOURCES.md)에 있다. DB는 편집 가능한 세 단의 저장소 도형으로 바꿨으며 이전 PostgreSQL 브랜드 아이콘은 수정본에서 제거했다.

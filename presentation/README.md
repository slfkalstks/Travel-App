# 여정 기획 발표

[최신 PPTX 수정본 다운로드](여정_기획발표_수정본.pptx)

16:9, 총 7장이다. 실제 앱 시연 없이 화면과 구조도로 설명한다.

1. 표지: 앱 이름과 아이콘·로딩 화면
2. 목차
3. 앱 소개와 장점
4. 실제 앱 화면으로 보는 핵심 사용 흐름
5. 기술 스택
6. 전체 시스템 구조
7. 현재 범위와 다음 단계

목차·본문·구조도·연결선·비교표는 편집할 수 있다. 한글은 **Malgun Gothic(맑은 고딕)**, 영문은 **Aptos**를 사용한다. 별도의 Noto 글꼴 설치가 필요하지 않으며 발표자 노트·메모·댓글은 제거했다. 기본 글꼴 안내: [Office 기본 테마](https://support.microsoft.com/ko-kr/office/foundations-experiences/new-office-theme), [맑은 고딕](https://learn.microsoft.com/en-us/typography/font-list/malgun-gothic).

## 화면과 자산

- 실제 홈·일정·목적지 화면은 [자산 출처](assets/ASSET_SOURCES.md)의 Simulator 원본 PNG다. 모니터나 창 주변이 들어 있지 않다.
- 표지의 아이콘·로딩폰은 요청에 따라 생성한 시작 화면 디자인 콘셉트다. 실제 앱 시작 기능이 구현됐다는 증거로 사용하지 않는다.
- 현재 JSON·파일 저장과 후속 PostgreSQL·API 연동은 구조도에서 구분한다. 기술·외부 API 근거는 [기술 선택 문서](../docs/planning/03_기술스택_선정과_비교.md), [구조도 출처](../docs/planning/assets/ASSET_SOURCES.md)에 있다.

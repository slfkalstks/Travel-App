# 여정 기획 발표

[PPTX 다운로드](여정_프로젝트_기획발표.pptx)

16:9, 총 5장이다. 실제 앱 시연 없이 화면과 구조도로 설명하는 대학 기획 발표 자료다.

1. 여정의 기획 의도와 목표 사용자
2. 실제 앱 화면 3개로 보는 핵심 흐름
3. 현재 구성과 후속 설계, API 연결
4. 기술 스택 선택과 대안 비교
5. 현재 범위와 다음 단계

본문·구조도·연결선·비교표는 편집할 수 있다. 앱 화면은 실제 iOS 시뮬레이터 캡처 이미지다. 상세 설명과 자료 출처는 각 슬라이드의 발표자 노트에 넣었다.

## 글꼴

앱과 같은 **Noto Sans KR**을 사용했다. 글꼴은 PPTX에 포함하지 않았다. 동일한 모양으로 편집·발표하려면 사용할 PC에 [프로젝트에 포함된 글꼴](../app/composeApp/src/commonMain/composeResources/font/noto_sans_kr.ttf)을 설치하고 PowerPoint를 다시 열면 된다. [폰트 라이선스](../docs/FONT_LICENSE.txt). 사용자 지정 글꼴 설치 안내는 [Microsoft 지원 문서](https://support.microsoft.com/en-us/powerpoint/use-decorative-fonts-from-third-party-vendors)를 참조한다.
